I would like to add a new `linker` agent to the `#research_swarm` xprompt swarm. Can you
help me implement this?

- We would achieve this by adding a new `linker=<true|false>` input that default to
  `false`.
- The new linker agent should be run whenever `linker=true` OR `image=true`.
- When the linker agent will be run, the lead agent should be instructed to use the
  `__final` research markdown filename suffix. This suffix should be added to the list
  of suffices the corresponding file hook uses to ignore certain research files.
- The linker agent should be instructed to create the actual file that the corresponding
  file hook will use.
  - The linker should use the research file generated by the lead researcher agent to
    create the refined file.
  - The new file should duplicate the meaning and intent of the lead's document. The
    linker agent should NOT attempt to do its own research.
  - The new file should use a well thought out and organized structure using unnumbered
    markdown sections.
  - If `image=true` (i.e. the image agent generated an image), then the linker should be
    instructed to embed that image into the new markdown file in an appropriate
    location.
  - The linker agent should be instructed to ensure that all referenced links in the
    lead's file are valid, but it should also attempt to add local links that allow the
    user to jump to different parts of the file when possible (no table-of-contents
    though).
- As a part of this change, we should remove the critique agent from this swarm (which I
  never use) and add a new `image_model` input so the image agent's model can be set
  explicitly.
- Review the research_swarm_linker_agent.md file in the research sidecar repo for
  context and inspiration before planning.

Think this through thoroughly and create a plan using your `/sase_plan` skill. Choose
and author the appropriate tier, validate and revalidate until it passes, then submit it
with `sase plan propose` (as the skill instructs) before making any file changes.
