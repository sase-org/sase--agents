Can you help me add a new `/` (filter) keymap to the help panel pop-up that is triggered via the `?` keymap?

- This keymap should trigger a filter bar that the user can type into to filter the keymaps that are shown in this
  panel.
- This panel should re-render automatically in live time as the user types.
- The goal is to make it easy to search for keymaps that are relevant only to a particular tab in the TUI.
- I want you to lead the design on this one. Make sure you design this feature so it is intuitive, reliable, and (last
  but not least) beautiful!

Think this through thoroughly and create a plan using your `/sase_plan` skill. Choose and author the appropriate tier,
validate and revalidate until it passes, then submit it with `sase plan propose` (as the skill instructs) before making
any file changes.
