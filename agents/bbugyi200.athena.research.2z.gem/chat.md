## Executive Summary & Verdict

Adding a `linker` agent to `#research_swarm` (running when `linker=true` OR `image=true`), removing the unused `critique` agent, and making `image_model` explicitly configurable is a **valuable and well-justified improvement**.

Most critically, this solves the **orphaned infographic problem** across the SASE research sidecar: previously, the infographic agent (`.image`) executed after the lead consolidator (`.final`) had already finalized and committed `<name>/<name>.md`. Consequently, the markdown report never embedded the image, and the [`research-highlights`](file:///home/bryan/.local/state/sase/workspaces/sase-org/sase/sase_47/sase/repos/linked/sase-research-artifacts/src/sase_research_artifacts/provider.py#L94-L121) file hook rendered Highlights PDFs for the Obsidian queue without visual summaries.

However, **there is a severe trap in the proposal's requirement regarding file-hook suffixes**:
- The prompt proposes adding `__final` to the *"list of suffices the corresponding file hook uses to ignore certain research files."*
- In reality, [`RESEARCH_HIGHLIGHTS_HOOK_SPEC`](file:///home/bryan/.local/state/sase/workspaces/sase-org/sase/sase_47/sase/repos/linked/sase-research-artifacts/src/sase_research_artifacts/provider.py#L94-L121) does **not** maintain a list of filename suffixes. It already filters out all files matching `!20*/*/*__*.md`. Thus, `<name>__final.md` is **automatically ignored by existing path globs**.
- Meanwhile, the only suffix list in the provider is [`_SWARM_RESEARCHER_SUFFIXES`](file:///home/bryan/.local/state/sase/workspaces/sase-org/sase/sase_47/sase/repos/linked/sase-research-artifacts/src/sase_research_artifacts/provider.py#L46), which generates **agent name vetoes** (`agent_name_globs`). If `final` were added to that list, the hook would veto any file added by `research.*.final`. **This would silently break all default swarm runs (`linker=false` and `image=false`)**, preventing Highlights PDFs from being generated when the lead agent writes the publication report.

With that trap avoided and 5 key adjustments adopted, the plan is ready for implementation.

## Critique of the Proposed Plan

### 1. Strengths
- **Resolves the Infographic Pipeline Disconnect:** Guaranteeing that the linker runs whenever `image=true` ensures every generated infographic is embedded into the publication markdown before the file hook fires.
- **Structural Standardization:** Consolidating reports into clean, unnumbered markdown headings (`## Section`, `### Subsection`) avoids rigid numerical schemes (`1.1.2`) that break across reorganizations.
- **Ergonomic In-Text Navigation:** Adding contextual jump links (`[see Findings](#findings)`) without generating an unwanted Table of Contents (TOC) significantly improves Obsidian and GitHub reading experiences.
- **De-clutters Swarm Architecture:** Removing the unused `critique` agent eliminates dead template weight, reduces prompt complexity, and reclaims capacity budget.

### 2. Critical Gotchas & Failure Modes
1. **The File Hook Suffix Trap:**
   As demonstrated above, [`provider.py`](file:///home/bryan/.local/state/sase/workspaces/sase-org/sase/sase_47/sase/repos/linked/sase-research-artifacts/src/sase_research_artifacts/provider.py#L46) must **not** be modified to add `final` to `_SWARM_RESEARCHER_SUFFIXES`. Path filtering is already handled via wildcard `!20*/*/*__*.md`.
2. **Infographic Stem Pollution via `#fork:`:**
   [`research_image.md`](file:///home/bryan/.local/state/sase/workspaces/sase-org/sase/sase_47/sase/repos/linked/sase-research-artifacts/src/sase_research_artifacts/xprompts/research_image.md#L6-L8) generates an image named `<source-stem>_infographic.png`. If the lead agent produces `<name>__final.md`, `#fork:research.{@1}.final` inherits a stem of `<name>__final`, yielding `<name>__final_infographic.png`. The prompt must explicitly instruct the image agent to strip `__final` and author `<name>_infographic.png`.
3. **Artifact Discovery via `wait.artifacts`:**
   Downstream agents in SASE swarms rely on `wait.artifacts` to locate upstream outputs. If the lead researcher does not register `<name>__final.md` via `sase artifact create`, the linker agent cannot locate it through `wait.artifacts`.
4. **Risk of LLM Semantic Compression:**
   Editing/refining LLMs often aggressively summarize or smooth over technical arguments. The linker prompt requires strict negative constraints forbidding text shortening, omission of tables/citations, or altering technical findings.
